Get a Single Post by ID

Use this endpoint to fetch one specific post from the JSONPlaceholder test API. It is the fastest way to check whether your integration is reading data correctly.

The request

GET https://jsonplaceholder.typicode.com/posts/1

The 1 at the end of the URL is the post ID. Change it to fetch a different post. Valid IDs are 1 through 100.

Example

curl https://jsonplaceholder.typicode.com/posts/1

Example response

{
  "userId": 1,
  "id": 1,
  "title": "sunt aut facere repellat provident occaecati excepturi optio reprehenderit",
  "body": "quia et suscipit\nsuscipit recusandae consequuntur expedita et cum\nreprehenderit molestiae ut ut quas totam\nnostrum rerum est autem sunt rem eveniet architecto"
}
FieldWhat it is
userIdThe ID of the user who wrote the post
idThe post's unique ID — this matches the ID you asked for
titleThe post's headline
bodyThe full text of the post

Notes

  • The endpoint only supports GET. Sending data to it has no effect.
  • Requesting an ID outside 1–100 (for example /posts/999) returns an empty response, not an error — see Troubleshooting below.
  • Responses are always JSON. No authentication is required.
